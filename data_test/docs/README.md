# data_test documentation

The `data_test/` bundle builds and shares a larger Medical GraphRAG index without
changing the core `harness/` or `graphrag/` code.

- [`bundle.md`](bundle.md) — what the bundle contains, how the scripts fit together,
  and how to verify, download and query it.
- [`kaggle.md`](kaggle.md) — the Kaggle run guide, including the one-command flow.

Design and rationale live in [`../plan_data.md`](../plan_data.md).
