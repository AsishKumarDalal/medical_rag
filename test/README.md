# test/

Every script that proves something works. `pytest` runs the `test_*.py` files.

```
test/
  data/
    test_data_fetch.py     # G0: fetch 20–30 articles, write manifest
    corpus/                # git-ignored, regenerated by the script
    fixtures/              # small committed HTML samples for offline tests
  test_fetch.py            # cleaning + manifest, no network
  eval/
    questions.json         # G4: local / global / unanswerable
    run_eval.py
```

Conventions:

- Unit tests never hit the network or a live model; stub both.
- One test file per behaviour under test, named for the behaviour.
- A test that needs the real corpus skips with a clear message when it is absent.
- Scripts that are demonstrations (not assertions) are still runnable: `python test/<name>.py`.
