# H6 — Minimal terminal

**Status:** complete (`f6efeea`)

## What was built

- `python -m harness` REPL with `/new`, `/resume <id>`, `/sessions`, `/usage`,
  `/help` and `/exit`.
- Tool calls are shown compactly; final answers, usage and compression notices are
  printed with plain `input()` / `print()`.
- Ctrl-C cancels the current turn, not the process.
- `--once` and piped stdin make the CLI scriptable for tests.
