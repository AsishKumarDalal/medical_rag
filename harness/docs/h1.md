# H1 — Agentic loop

**Status:** complete (`68dd9cf`)

## What was built

- `harness/config.py` — environment-driven settings, validates the model window and
  the 50k prompt + output ceiling; one place for model, temperature and token caps.
- `harness/messages.py` — typed `Message` / `ToolCall` objects and conversion at the
  provider boundary; usage and token-accounting hooks.
- `harness/llm.py` — the single model doorway: retries with backoff, response
  normalization, secret redaction, one `complete()` interface.
- `harness/loop.py` — `run_turn()` copies the conversation, calls the model,
  dispatches tool calls, appends `role="tool"` results and stops on a response with
  no tool calls; iteration and model failures return a transcript instead of
  raising.
- `EchoTool` — the trivial tool used to prove the loop.

## Verification

.venv/bin/python -m pytest test/test_loop.py test/test_messages.py test/test_config.py -q

The live proof is `test/docs/smoke-h1.md`: the model received the `echo` tool,
returned a structured tool call, read the tool result, and answered in two model
calls (`stop_reason=answer`).

## Boundaries

No persistence, context compression, security policy or RAG in this phase; those
are H3–H5 and G3.
