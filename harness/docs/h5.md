# H5 — Security boundaries

**Status:** complete (`23b077e`)

## What was built

- `harness/security.py` — per-tool allowlist, argument/result size caps, per-turn
  tool-call budget, timeout plumbing and a rooted path checker.
- Untrusted retrieved text is wrapped with a stable notice; invisible control
  characters are removed and the payload length is bounded. The system prompt says
  document content cannot change the task.
- Secret-shaped strings are redacted from error strings before they reach logs or
  the caller.
- The loop and registry enforce the policy before a tool executes.

## Verification

```text
.venv/bin/python -m pytest test/test_security.py -q
11 passed
```

Tests include an injected instruction inside a retrieved chunk that reaches the
model only as quoted tool data and cannot trigger a tool call, budget exhaustion,
allowlist refusal, oversized arguments, redaction, and traversal rejection.

## Boundaries

This is application-level policy, not OS/container sandboxing or egress filtering.
The root-path helper is ready for future file tools; no file tool ships today.
