# G4 — Evaluation

**Status:** question set and runner complete; live measurements are recorded
once the G1 index is built. The offline baseline runs without a model.

## Question set

`test/eval/questions.json` contains 30 hand-written questions:

- **15 local** — named entities, with hand-marked relevant chunks;
- **8 global** — themes or corpus overview, forced to `mode=global`;
- **7 unanswerable** — must abstain (`must_abstain=true`).

Each entry has an `id`, `shape`, `question`, `mode` and, for local questions,
`relevant_chunks`.

## Runner

`test/eval/run_eval.py` loads the real `GraphRagEngine` and records per question:

- route and mode;
- `abstained`;
- citations;
- `recall@k` against the marked chunks;
- citation coverage against real artifact ids;
- latency, model calls and errors.

It refuses to score a citation that does not resolve. Each finished row is
appended to `results.partial.jsonl`, so an interrupted live run resumes with
`--resume` instead of re-billing every call. The corpus/index hashes are stored
with the results so a table cannot be confused with a different index.

## Metrics

- **Local recall@k** — mean fraction of marked relevant chunks present in the
  first `k` evidence chunks.
- **Abstain accuracy** — fraction of the seven unanswerable questions that
  correctly abstain.
- **Citation coverage** — fraction of returned citations that resolve to a real
  chunk or community id.
- **Errors, average latency, total model calls**.

## Commands

```bash
# deterministic baseline, no network
.venv/bin/python test/eval/run_eval.py --offline

# full live run
.venv/bin/python test/eval/run_eval.py --live --k 8

# small live smoke subset
.venv/bin/python test/eval/run_eval.py --live --ids L01 L06 U01

# resume an interrupted live run
.venv/bin/python test/eval/run_eval.py --live --resume
```

Outputs:

- `test/eval/results.json` — full rows + summary + snapshot;
- `test/eval/results.partial.jsonl` — resumable per-question rows;
- a markdown table printed to stdout for `docs/eval.md`.

## Reading the results

A good result is not only high recall: the pipeline must also abstain on the
seven out-of-scope questions and keep citation coverage at 1.0. A regression in
either is a retrieval-quality bug even if the average recall rises.

## Boundary

The evaluation measures this corpus and this index. It is not a clinical
benchmark and says nothing about diagnostic accuracy on real patients.
