# G0 — Reproducible medical corpus

**Status:** complete (`6ff0ef4`; corpus proof in `test/docs/g0-corpus.md`)

## What was built

- `test/data/test_data_fetch.py` — 24 Wikipedia medicine topics fetched through the
  plain-text extracts API, polite 2 s pacing, retries with backoff on HTTP 429,
  deterministic slugs, one file per article, and a resumable merge into
  `manifest.json` (URL, title, fetch time, sha256, character count).
- `test/data/corpus/` — git-ignored; 24 files, 260,462 characters.
- `test/test_fetch.py` — 8 offline tests over a committed three-article fixture:
  cleaning removes navigation/boilerplate, ids are stable, no article is empty,
  and the manifest is consistent.

## Reproduce

```bash
.venv/bin/python test/data/test_data_fetch.py --pause 2
.venv/bin/python -m pytest test/test_fetch.py -q
```

Interrupted fetches resume from the existing files and manifest; `--force`
refetches everything. The full article table is in `test/docs/g0-corpus.md`.

## Boundary

Personal research use only. The corpus is cached, not committed, and is not a
clinical reference.
