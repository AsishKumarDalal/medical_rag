# G2 — Query pipeline

**Status:** implemented and covered by offline tests; live smoke queries are
recorded once the G1 index is built.

## Entry points

- `graphrag.answer(question, mode="auto", k=8)` — loads the index and answers.
- `GraphRagEngine.load(config, llm)` — reusable engine for many questions.
- `python -m graphrag.ask "…"` — CLI (`--mode`, `--k`, `--json`).
- `GraphRagBackend` — the harness-facing wrapper used by G3.

## Route (Q0/Q1)

The question is embedded once (`probe`) and, in `auto` mode, one cheap model call
classifies it as:

- **local** — names or implies specific entities;
- **global** — asks for themes, coverage or a corpus overview;
- **abstain** — clearly outside the corpus.

A failed or unparseable router answer falls back to local; an explicit
`--mode local|global|abstain` skips the router entirely.

## Local path

1. **Seeds (Q2)** — two doors, merged and capped at `GRAPHRAG_MAX_SEEDS`:
   - name matching: exact key, normalized key, containment, meaningful tokens;
   - vector similarity over node vectors.
   With the hash backend, a vector seed must also share a content word with the
   question; real embeddings keep the pure cosine door.
2. **Expand (Q3)** — a two-hop walk (`GRAPHRAG_WALK_HOPS`) in both directions,
   bounded to 120 visited nodes and 500 edges. Every fact keeps its
   `source_chunks`.
3. **Fetch chunks** — top chunks by vector similarity above
   `GRAPHRAG_CHUNK_THRESHOLD`; the hash backend also requires shared content
   words and rescales by overlap.
4. **Rank (Q4)** — each fact scores:
   `0.55 × semantic + 0.30 × structural + 0.10 × mentions + 0.05 × chunk support`.
   The shortlist goes through `rerank()` in `rerank.py`; the LLM may only
   reorder supplied candidates, and invalid output falls back to deterministic
   order.
5. **Evidence** — `k` chunks, ranked chunks first, then the first source chunk
   of each selected fact.
6. **Narrate (Q5)** — the model sees ranked facts and source passages wrapped as
   untrusted text and must answer with inline `[article::chunk]` citations. A
   refusal becomes an abstention, not a cited answer.
7. **Verify (Q6)** — every citation is checked against real chunk/community ids;
   unsupported citations and uncited sentences are reported in
   `result.verification`.

## Global path (QG)

1. Score every community summary against the question (LLM map; lexical fallback
   when the model is unavailable).
2. Keep the best communities (threshold 35, at most `max(2, min(k, 4))`).
3. Reduce the selected summaries into one answer citing community ids.
4. Verify citations and abstain if no community is relevant or the narrator
   refuses.

## Result contract

`QueryResult` contains:

- `answer`, `citations`;
- `evidence` (facts, chunks or communities with scores);
- `mode` (`local`, `global`, `abstain`), `route`;
- `abstained`, `fallback`, `verification`, `stats`, `error`.

Every returned citation resolves to a real chunk or community id. When nothing
supports the question, the result abstains with no citations.

## Configuration

| Variable | Default | Effect |
|---|---|---|
| `GRAPHRAG_WALK_HOPS` | 2 | graph expansion depth |
| `GRAPHRAG_MAX_SEEDS` | 6 | maximum seed entities |
| `GRAPHRAG_SEED_THRESHOLD` | 0.65 | vector seed cutoff |
| `GRAPHRAG_CHUNK_THRESHOLD` | 0.30 | chunk vector cutoff |
| `GRAPHRAG_RERANK_KEEP` | 15 | reranker shortlist size |
| `GRAPHRAG_LLM_RERANK` | true | enable the LLM reranker |

## Reproduce

```bash
.venv/bin/python -m graphrag.ask --mode auto "What is asthma?"
.venv/bin/python -m graphrag.ask --mode global "Summarize the main diseases"
.venv/bin/python -m graphrag.ask --json "What is asthma?"
.venv/bin/python -m pytest -q test/test_graphrag_query.py
```

## Boundary

The answer is limited to the indexed medical literature. The pipeline is not a
diagnostic tool: it must abstain when the corpus lacks evidence and must keep
citations attached to every claim.
